分享管理已统一为笔记管理：features/notes、Note组件、/notes页面及/api/v1/notes接口；权限与API密钥scope同步改为notes。旧/shares页面跳转到新页面，旧后台API由后端兼容。后端需先手动重启以执行新增表重命名迁移，再刷新管理端；不清空既有笔记。C端和B端继续使用独立接口与授权。


## C端写笔记入口（2026-11-16）

C端“写笔记”在新浏览器窗口/标签页打开 `/notes` 列表，保留C端页面，不自动打开新建弹窗；管理端仍由既有 `notes.use` / `notes.create` 权限和后端校验控制。`/notes?view=trash` 可直接进入回收站筛选，恢复和彻底删除仍使用既有管理端权限与后端校验。C/B端复用后端 `DW_SESSION` 会话，不通过链接传递登录凭证。

本机开发时，API 的 localhost/127.0.0.1 与当前页面主机名自动对齐，使 C端代理写入的同主机Cookie能在B端直接请求8070时携带；生产或远程API地址不受影响。线上两端需连接同一会话API，当前仅验证本机配置。此变更不需要新增后端接口或重启后端。
