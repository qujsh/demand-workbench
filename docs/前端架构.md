# 前端架构

## 技术栈

- Vite：开发服务器、构建和环境变量。
- React：组件和页面渲染。
- TypeScript：领域模型、接口数据和组件属性约束。
- Ant Design：表单、日期、下拉框、抽屉、弹窗、提示等通用交互组件。
- Tailwind CSS：页面布局、间距、尺寸和响应式工具类。
- TanStack Query：服务端请求、缓存、轮询、请求取消和错误状态。
- React Router：页面 URL、导航和浏览器前进后退。

## 目录职责

```text
src/
├── app/                    # Router、Provider、主题和应用入口
├── features/               # 按业务功能组织
│   └── decomposition/
│       ├── api/            # 接口函数和响应 Schema
│       └── hooks/          # 功能级组合 Hook
├── shared/
│   ├── api/                # 通用 HTTP 客户端
│   └── types/              # 跨功能共享的稳定类型
├── components/             # 待逐步迁入 features 的旧组件
├── data/                   # 演示数据
└── test/                   # 测试公共配置
```

现有 `components` 是渐进迁移区。修改某个旧组件时，应优先把它迁入对应 `features`，而不是继续扩大该目录。

## 依赖方向

```text
app -> features -> shared
```

- `shared` 不得导入 `features` 或 `app`。
- 功能模块之间不得直接读取彼此内部文件；跨模块能力通过公开入口或共享类型协作。
- 页面负责组合，不负责 HTTP 协议、缓存和轮询细节。

## 路由

```text
/requirements
/requirements/:requirementId/analysis
/requirements/:requirementId/planning
/requirements/:requirementId/publish
```

页面刷新后必须可以根据 URL 恢复当前位置。新增主页面必须注册路由，不使用根组件字符串状态模拟页面跳转。
