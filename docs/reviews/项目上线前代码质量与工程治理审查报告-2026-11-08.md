## 1. 结论与审查边界

**有工程基础，但尚不能批准直接生产上线。** React/TypeScript、TanStack Query、Zod、Spring Security、MyBatis、Flyway 与真实 MySQL 集成测试已形成有效基础；无需推倒重写。主要缺口集中在秘密配置、可复现交付、生产环境隔离、公开分享闭环与验收证据。

前端 HEAD `41c757193e6f7e2ea406eed440bf97ccd595a2c3`；后端 HEAD `50c5bc143779c99688249fb6cb451f7e5878cc32`。两端分支实际名为 `release-0.0.2`，不是字面 `0.0.2`。前端初始干净；后端 application.yml 原有未提交修改保留，报告对 HEAD 和工作区结论作区分。

0.0.2 已明确下线需求构想、AI拆解、任务发布、C端承接、交付验收。它们属于历史范围，不应列为本版必须恢复的功能；如用户实际预期仍包含这些模块，需重新确认发布范围。保留的成长信用及分类不等于任务业务仍在线。

证据等级：本报告条目包含代码事实与条件性部署风险，云端 ACL、凭证有效性和生产环境状态未经实测。没有访问业务数据库数据，没有变更原库，没有调用真实短信、AI或上传服务，没有执行浏览器E2E。集成测试自行创建/销毁隔离 Testcontainers MySQL。不能宣称已经完成生产安全认证、性能压测或所有动态引用的形式化证明。

## 2. 架构与分域评价

前端 app→features→shared 大体合理，主页面已有懒加载，API集中且使用边界Schema，异步审核/合并轮询由Query管理，没有把它们降级为页面定时器。旧 components 目前主要为侧栏和图标。分享核心页面仍过重，CSS颜色与布局值集中但硬编码较多，建议保留视觉渐进提取Token，不能为规范重做页面。

后端按 identity/shares/openplatform/mcp/discovery/storage 组织，Controller多数负责参数和响应，应用端口隔离外部实现。MyBatis、JdbcTemplate与JSON快照并存增加维护面，但不构成必须整体重写的理由。分享正式状态、JSON与关联表同事务更新，乐观版本、owner隔离、审核租约和原子放行是明确优点。应用层仍使用事务/Service注解；应明确项目所谓domain/application“不依赖框架”的实际边界，而非机械清除所有Spring注解。

数据库承担账号、会话、分享、审核和密钥的正式持久化职责，不是可随意丢弃的测试缓存。MySQL 8.4本身可作为生产数据库，无需改数据库产品；当前本机单容器部署只证明开发运行。没有证据证明它当前已承担外部生产流量。生产建议独立托管MySQL或具备监控备份的专用实例，迁移经确认后按备份→恢复到隔离实例→校验→停写增量同步→切换→回滚窗口执行。

## 3. 业务流程与安全核对

| 流程 | 已核实的保护 | 剩余风险/验收 |
|---|---|---|
| 登录与账号 | 随机不透明会话令牌、数据库仅存SHA-256摘要、账号状态检查；非JWT，无需凭空新增JWT刷新 | 代理Cookie/IP、短信锁等待、生产秘密配置 |
| 密码重置 | 手机用途隔离、有限尝试、密码保存后Repository撤销全部会话 | 需在真实代理回归登录及重置；没有把未读下层实现误判成缺失撤销 |
| 角色/管理端 | 后端业务权限拦截及Service授权；账号管理不只靠前端菜单 | 新API权限映射易漏，持续增加负向授权矩阵 |
| 分享/公开 | owner条件、版本、正式与编辑副本、公开只读白名单、仅approved匿名可见 | 无匿名前端页面；云ACL及HTTPS未验 |
| 图片/头像 | 定向insertOnly Key、MIME/尺寸核验、完成后关联、本人校验、私有签名300秒 | 撤回后已签URL仍有至多有效期窗口，不承诺瞬时收回；配额与孤立对象 |
| 标签合并/审核 | 数据库持久化、租约、限并发、断点、短事务；审核调用在事务外、75秒超时、有限重试 | 重启/多实例故障演练待补，日志仅记录异常类型对深度排障不足 |
| MCP/API Key | 独立Bearer、scope与实时权限、拒绝Origin、256KB请求限制、摘要存储、审计 | 数量并发竞争、边缘频控及调用成本治理需预发布验证 |

SQL主要使用绑定参数，动态时间线列来自白名单，未确认可利用SQL注入。富文本React转义、链接协议白名单、后端节点/深度/数量限制形成保护，未确认可利用XSS。上传不接受任意服务端URL下载，未确认SSRF。上述是已读调用链结论，不是“没有漏洞”的保证。Cookie使用SameSite=Lax且写接口POST+JSON；CSRF被关闭，应测试同站非受信子域、来源策略及实际部署，不能仅凭关闭就宣称可跨站利用。CORS不是授权机制。

前后端分享visibility/status大小写在API边界转换、错误信封与版本字段总体一致。schema回归用例可运行；分享时间前端按浏览器时区、年月定位后端固定Asia/Shanghai，非中国时区用户的月份边界需专门确认，目前不直接认定为缺陷。
