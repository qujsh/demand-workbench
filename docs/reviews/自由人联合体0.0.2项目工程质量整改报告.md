决定不改：当前内部测试每日默认200次的业务规模，尚无真实慢响应/等待分布证明可用性瓶颈；贸然拆事务需重新设计发送中状态、旧挑战覆盖、服务商outId与一次性消费，属于认证语义变化。保留现有配额不回退、有限错误尝试、一次性消费及重置密码撤销会话。原短信测试随完整测试运行；没有声称执行过慢服务/多用户压测或改善吞吐。后续触发条件：认证延迟、全局bucket锁等待、池耗尽指标出现实质问题，届时独立设计和故障测试。
