# 账号密码与阿里云个人短信认证接入

更新：2026-11-05。后端位于 `/Users/mainto/javafile/demand-workbench-backend`。

## 页面入口

沿用前端开发服务 `http://localhost:4173`：

- `/login`：默认手机号＋密码登录；未登录访问业务页面时同样显示默认密码登录。
- `/login/sms`：验证码登录，新手机号验证后自动注册。
- `/password/set`：为已注册、尚未设置密码的手机号首次设置密码。
- `/password/forgot`：短信验证后重置密码。
- `/settings`：本人密码状态、设置／重置密码入口与登录设备。

页面沿用原登录背景、蓝色主色、Ant Design表单。切换登录方式保留手机号，不保留密码和验证码。两次密码需一致，支持显示／隐藏密码；发送成功提供60秒重发冷却、脱敏号码与5分钟有效期提示。浏览器刷新与前进后退支持独立路径。已登录用户仍可进入设置／找回密码页；完成后所有设备需重新登录。

## 阿里云需要访问的页面

使用**号码认证服务PNVS的短信认证**，不是普通短信SMS，不需要企业自定义签名。

1. [号码认证控制台](https://dypns.console.aliyun.com/)：个人实名认证后，按照官方指引开启短信认证和融合认证功能。
2. 在该控制台“短信认证”内查看平台**赠送签名和赠送模板**。选择登录／注册模板，以及重置密码场景模板；复制实际签名和模板CODE，不要直接抄文档示例值。当前模板变量约定 `code`、`min`；如选择了不同变量的模板，需相应调整适配器。
3. [RAM访问控制](https://ram.console.aliyun.com/)：创建服务端专用RAM用户AccessKey，按最小权限授予下方两个操作。不要把密钥发到聊天或填进前端。
4. [官方新手指引](https://help.aliyun.com/zh/pnvs/getting-started/sms-authentication-service-novice-guide)、[产品计费与套餐](https://help.aliyun.com/zh/pnvs/product-overview/product-pricing)。本服务购买“短信认证套餐”，普通短信SMS套餐不能抵扣。

最小RAM策略：

```json
{
  "Version": "1",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["dypns:SendSmsVerifyCode", "dypns:CheckSmsVerifyCode"],
    "Resource": "*"
  }]
}
```

## 后端配置

在启动后端的IDE Run Configuration → Environment variables，或服务器进程环境中配置：

```dotenv
IDENTITY_SMS_PROVIDER=ALIYUN
IDENTITY_SMS_ACCESS_KEY_ID=填写RAM用户AccessKeyId
IDENTITY_SMS_ACCESS_KEY_SECRET=填写RAM用户AccessKeySecret
IDENTITY_SMS_SIGN_NAME=填写平台赠送签名
IDENTITY_SMS_LOGIN_TEMPLATE=填写登录注册模板CODE
IDENTITY_SMS_PASSWORD_TEMPLATE=填写重置密码模板CODE
IDENTITY_SMS_DAILY_LIMIT=200
```

上述值只进入后端。不要使用 `VITE_` 前缀，不要把配置提交Git。Spring Boot默认不会自动加载仓库 `.env`；必须由IDE或启动脚本注入进程环境。后端 `.env.example` 已增加字段说明。

完成后手动重启共享后端 `http://localhost:8080`，Flyway自动执行 `V202611051000__password_and_sms_authentication.sql`。已有账号密码保持未设置，不分配默认密码；原手机号和会话数据保留。已有账号先用真实验证码登录，再到个人设置设置密码，之后可默认使用密码登录。

本轮未重启用户已有的8080服务；前端开发服务支持热更新。只刷新前端不能加载新的后端接口。

## 安全规则与实现

- 密码保存随机盐BCrypt哈希，成本12；不回传哈希，不存储明文。
- 发送API要求阿里云生成验证码 `##code##`，`ReturnVerifyCode=false`；核验须同时检查成功状态、`Model.VerifyResult=PASS`和对应OutId。
- 登录、首次设置密码、重置密码使用独立场景名称及数据库用途，验证码不能跨用途使用；只保存流水和有效期，不保存真实验证码。
- 5分钟有效，最多5次错误，成功即消费；行锁保证并发消费安全。计数不会因HTTP业务错误回滚。
- 手机号全用途共享60秒冷却、24小时10次；IP每小时20次；系统24小时默认200次。密码登录每手机号15分钟10次、IP每分钟30次。成功登录也计入频控窗口；IP来自连接地址，不信任客户端自行传入的转发头。反向代理部署需按可信代理配置真实IP，并配合边缘防刷。
- 系统发送限额按尝试次数计算，服务商失败也占用配额；它是应用防刷限额，不是云账号硬性费用封顶。控制台还应配置用量告警。
- 设置与重置密码均撤销全部会话；首次设置不覆盖已有密码。未注册手机号先验证码注册，错误账号与错误密码使用相同登录提示。
- `S048100012`密码错误401、`S048100013`频控429、`S048100014`未配置503、`S048100015`供应商异常503、`S048100016`重复首次设置409、`S048100017`密码规则400、`S048100018`已验证但未注册400。
- 生产需HTTPS；HTTPS请求下登录Cookie附带Secure，默认HttpOnly/SameSite=Lax。域名与代理转发协议应正确配置。

供应商文档：[发送验证码](https://help.aliyun.com/zh/pnvs/developer-reference/api-dypnsapi-2017-05-25-sendsmsverifycode)、[核验验证码](https://help.aliyun.com/zh/pnvs/developer-reference/api-dypnsapi-2017-05-25-checksmsverifycode)。

## 本地隔离验证

只有显式 `spring.profiles.active=local` 且 `IDENTITY_SMS_PROVIDER=DEVELOPMENT` 时允许固定测试码123456；默认配置和生产配置拒绝开发模式。测试响应也不会返回验证码。禁止在共享／生产环境启用该模式。

自动化覆盖页面切换、发送失败、冷却、确认密码、密码登录、验证码用途隔离、一次消费、错误次数、BCrypt保存、密码更新后的旧会话撤销。真实数据库使用隔离MySQL，短信发送和核验使用local替身；阿里云SDK的成功／失败及流水校验另有适配器契约测试。尚未配置真实阿里云账号前，不能宣称真实手机已收到短信。
