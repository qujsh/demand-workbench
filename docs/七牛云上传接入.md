# 七牛云上传接入

## 本轮范围

任务发布页的封面、展示图片、视频、参考附件使用后端登记后直传七牛云。暂不新增头像、回报图片、内部附件或交付文件上传入口；后续入口应复用同一登记流程，新增明确场景，不自行拼接对象路径。本轮不实现定时清理、删除对象或迁移存量本地媒体。

## 配置

在共享 Spring Boot 后端的运行环境（例如 IDE 的 Environment variables）配置，不能配置到 Vite：

```dotenv
QINIU_ENABLED=true
QINIU_ACCESS_KEY=填写本机密钥
QINIU_SECRET_KEY=填写本机密钥
QINIU_BUCKET=空间名称
QINIU_UPLOAD_URL=https://对应空间区域的上传域名
QINIU_DOWNLOAD_DOMAIN=https://文件访问域名
```

上传域名从七牛控制台核对，必须匹配空间区域；后端 SDK 查询区域用于对象 stat，前端不持有 AK/SK。配置完成后手动重启后端，Flyway 自动创建 `media_upload` 表。默认禁用七牛；未配置时新上传明确提示尚未配置，不默默改存本地。启用七牛后旧 multipart 上传接口拒绝新上传，避免绕过场景登记。旧本地文件继续按原接口读取。

在七牛控制台为实际 B 端地址配置 CORS：允许开发及正式网站的精确 Origin、POST 方法和 Content-Type 请求头，允许读取上传响应。不要为直传携带业务 Cookie。正式页面使用 HTTPS 时，上传地址与访问域名都应支持 HTTPS。

公开空间知道对象URL即可访问，包括未发布的素材。需要保护草稿或私人文件时必须使用私有空间。本轮后端读取接口先执行现有媒体授权，再302跳转到5分钟签名地址；签名不能把公开空间变成私有空间。不得把合同、身份证明等私人材料放在当前公开任务素材场景。

## 上传协议

1. `POST /api/v1/task-media/upload-token?requirementNo=...`
   JSON：`{scene, filename, mimeType, size}`。要求当前需求编辑权限。
   返回：`{mediaNo, key, token, uploadUrl, expiresAt}`，时间为Unix秒。
2. 前端以 multipart 将 `token`、`key`、`file` 直传 `uploadUrl`，展示进度、支持取消。凭证有效期10分钟，限制唯一Key、只新增、精确大小、内容类型，启用七牛类型探测。
3. `POST /api/v1/task-media/complete?mediaNo=...`
   后端核对上传者和当前需求权限，调用七牛 stat 验证实际大小和类型。成功后在同一事务创建原有 `task_media` 记录并标记登记完成；重复确认幂等。
4. 保存业务表单仍使用 `mediaNos` / `coverMediaNo`。草稿与正式发布都检查媒体是否已确认、归属及封面类型；业务引用仍保存在现有发布草稿及版本快照中。

| 场景 | 对象前缀 | 支持类型 |
| --- | --- | --- |
| task_cover | task/cover/yyyy/MM/ | JPEG、PNG、WebP |
| task_image | task/image/yyyy/MM/ | JPEG、PNG、WebP |
| task_video | task/video/yyyy/MM/ | MP4 |
| task_attachment | task/attachment/yyyy/MM/ | PDF、ZIP |

路径月份按UTC生成，Key及扩展名均由后端生成；单文件最多50MB。浏览器先做类型检查，最终依赖云端内容探测与服务端stat核验。

`media_upload` 保存上传前登记的需求编号、上传者、场景、Bucket、Key、原始名称、期望大小/类型、凭证到期时间、确认时间和云端哈希。确认时间为空表示待确认，不能用于业务引用。取消或保存失败后登记保留，供后续清理使用，本轮不会删除。

## 当前空间先使用测试域名

已确认 `freeligo` 位于华东浙江（z0），为公开空间。七牛控制台提示当前CDN测试域名仅支持HTTP，不能将它直接写成HTTPS。

后端本机启动环境配置如下（测试域名请从控制台复制完整值）：

```dotenv
QINIU_ENABLED=true
QINIU_BUCKET=freeligo
QINIU_UPLOAD_URL=https://up-z0.qiniup.com
QINIU_DOWNLOAD_DOMAIN=http://从控制台复制的测试域名
QINIU_ALLOW_HTTP_TEST_DOMAIN=true
QINIU_ACCESS_KEY=在本机填写
QINIU_SECRET_KEY=在本机填写
```

默认仍要求HTTPS。测试开关只放行形如 `*.hd-bkt.clouddn.com` 的HTTP下载域名，不放行HTTP上传或任意HTTP域名。仅用于本地HTTP页面调试；HTTPS页面可能升级或阻止HTTP图片请求，因此正式HTTPS页面需改用已配置HTTPS的自定义域名，并关闭测试开关。测试域名到期后只更换访问域名配置，数据库里的对象Key不用改。

截图中跨域尚未配置。进入空间设置中的跨域设置，添加实际本地前端Origin（例如 `http://localhost:4173`，按实际端口填写），允许POST及Content-Type请求头。配置完成并在本机填好密钥后，手动重启后端，再做真实上传联调。
