# 开放平台与 MCP 接入

实现日期：2026-11-06。

入口：系统配置 → API 密钥与 MCP（独立页 `/system/api-keys`）。个人设置入口为系统配置 → 个人设置（`/system/settings`），旧 `/settings` 自动跳转。支持创建名称、权限范围和有效期，完整密钥仅展示一次，列表仅含脱敏元数据，支持撤销与Codex连接说明。

前端模块为src/features/open-platform，使用TanStack Query管理密钥列表和撤销；创建结果不进入Query或mutation缓存，仅在弹窗局部状态短暂保留。关闭即清除明文，不写localStorage/sessionStorage。服务端权限交集决定可执行操作，前端显隐不是安全边界。

后端模块：openplatform负责凭据持久化及生命周期，mcp负责无状态Streamable HTTP协议和分享工具适配。详情、部署和协议约束见后端docs/open-platform.md与docs/api.md。

首版支持普通文本创建/查询/更新私密分享；不包含公开申请、图片上传、删除、OAuth授权、调用计费或平台限流。密钥只访问MCP，不授予网页会话或账号管理权限。

### 密钥页面整理与永久有效

列表仅展示名称/脱敏前缀、权限摘要、状态、有效期及详情/撤销；编号、完整时间和权限标签在详情弹窗显示。连接说明默认显示，按创建密钥、配置Codex、检查工具三步组织；配置复制按钮放在代码块工具栏，诊断独立分区，小屏代码自动换行。

创建时validDays=0表示永久有效，expiresAt返回null，仍计入有效密钥数量限制、仍可撤销，账号实时权限校验不变；有效期必须显式提交，默认仍为90天。迁移V202611080010仅放宽expires_at为空，不更改既有密钥时间。

验证：`VITEST_MAX_WORKERS=2 npm run check`通过（126项测试）；后端OpenPlatformIntegrationTest七项真实MySQL测试通过。浏览器验证桌面1440×1100及手机390×844：永久密钥创建/刷新/调用/撤销、详情弹窗边界、默认显示连接说明、配置复制、诊断后清除密钥；无页面错误或整页横向溢出。截图保存在/tmp/key-layout-desktop.png及/tmp/key-layout-details-mobile.png。临时数据库与服务验证后清理。

### 密钥删除交互

脱敏密钥仅展示文本；密钥编号仍可复制。行操作改为确认删除，已撤销密钥也可删除。调用POST /api/v1/open-platform/keys/delete?keyNo=...，成功后刷新列表。后端复用deleted字段使凭据失效，不清理历史调用审计，不新增迁移，原revoke接口保留兼容。
