# 分享管理：实现与验证记录

更新：2026-11-03。前端 `/shares` 已从会话演示状态切换到登录用户的后端数据。本文件描述实际交付状态，与《分享管理前后端技术设计》配合阅读。

## 已接入的能力

- 创建和编辑记录；标题可选，正文保存为白名单富文本 JSON。服务端派生纯文本和标签，不相信客户端传入的标签、图片 URL 或用户编号。
- 手动保存草稿。正式记录的编辑草稿独立保存，未提交前不会覆盖正式内容；重新进入编辑器会恢复草稿。
- 关闭未保存编辑器时提供“保存草稿 / 放弃修改”，点击确认框周围空白取消退出。
- 回收站与恢复；恢复统一转为仅自己可见。保存、回收和恢复使用版本校验，冲突时保留本地编辑并提示刷新。
- 时间线按发生时间排列；草稿按更新时间、回收站按移入时间排列。发生时间、创建时间、首次公开保存时间分别保留。
- 搜索、标签、可见范围、年月筛选；每页 20 条，继续加载使用时间和编号组成的游标。
- 标签全部展示，最多 16 个单列，超过 16 个双列，遵循用户排序。管理标签支持整行拖动、删除、新标签插到顶部、相似标签提示和定位。完全重复名称由后端规范化去重。
- 图片直传接口、完成核验、记录绑定、登录鉴权预览。只接受 JPEG / PNG / WebP，每张最多 10 MiB、每条最多 9 张；列表最多 3 张缩略图。
- 原有编辑器放大、可滚动标签辅助栏、正文插入标签等交互保留。

## 后端与数据库

仓库：`/Users/mainto/javafile/demand-workbench-backend`。

业务包：`com.demandworkbench.shares`，分为 controller / application / domain / infrastructure。16 个接口统一使用 `/api/v1/shares`、GET / POST、Query 资源编号和既有响应信封。身份从登录会话获取；跨用户读取返回不存在。

Flyway：`V202611031200__create_share_records.sql`，新增 7 张表：`share_record`、`share_working_copy`、`share_tag`、`share_tag_order`、`share_media`、`share_record_tag`、`share_record_media`。无物理外键和 CHECK，字段具备中文注释和通用审计字段。

当前落库采用“索引字段 + JSON 聚合快照”：主记录保存完整富文本及编辑副本快照，独立副本表与关系表作为事务内同步的投影；不应直接改投影表作为业务写入入口。关系与副本采用软删除后重新激活，正文不会因删除标签而被改写。

每个用户的写事务通过 `share_tag_order` 行锁串行化，配合记录版本和排序版本避免并发覆盖；客户端创建编号提供幂等重试。只回写实际变化的记录、标签或媒体。

列表、计数与年月查询现已下推数据库，双向游标与窗口化页面支持连续浏览；详情与单条写入按编号加载。新增时间线索引、浮窗表和创建幂等索引。具体实现、30万条模拟容量验证与剩余性能边界见 [时间线定位与浮窗引用实现](时间线定位与浮窗引用实现.md)。

重启后端后 Flyway 自动建表，前端沿用 `VITE_API_BASE_URL`（默认 `http://localhost:8080`），需要登录；不自动导入原演示记录。

图片配置已于2026-11-04调整为默认继承已有七牛配置、可选分享模块覆盖；本人图片与公开图片分别按权限签发临时地址。详见 [分享图片访问与配置](分享图片访问与配置.md)。空间实际权限与CDN由七牛侧配置，本轮未更改云端权限。

## 本轮验证

- 分享前端专项：2 个文件、11 项测试通过；类型检查、ESLint 和生产构建通过。
- 分享后端：真实 Testcontainers MySQL 迁移与接口集成，另有富文本安全单测。覆盖用户隔离、幂等、版本冲突、正式内容与编辑草稿隔离、标签排序和去重、软删除、恢复、媒体归属和完成核验、游标边界。
