# 公开内容审核实现与验证

实现日期：2026-11-05。

## 使用效果

- 私密记录、草稿、上传图片、本人看图和图片地址续签均不触发内容审核。
- 选择公开后点击「提交公开审核」，确认后保存正式内容并建立异步任务；审核期间仍仅自己可见。
- 正文通过 DeepSeek 审核，图片通过阿里云图片审核增强版 `baselineCheck`。全部明确通过才实际公开。
- 记录卡片显示排队、分项进度、未通过、待确认、服务失败等状态；服务失败可点击重试。修改被拒内容后重新提交。
- 修改公开内容先转回私密，审核新版本后再公开；编辑草稿不改变原正式版本。撤回、删除、旧结果和过期执行者均不能绕过公开检查。

## 启用

后端重启时 Flyway 应用 `V202611050000__share_public_review.sql`。DeepSeek 使用现有后端 `spring.ai.openai` 配置，文本模型由 `SHARE_REVIEW_TEXT_MODEL` 控制。

图片审核需开通阿里云图片审核增强版、授予 RAM 权限，并设置后端环境变量 `ALIBABA_CLOUD_ACCESS_KEY_ID`、`ALIBABA_CLOUD_ACCESS_KEY_SECRET`；默认地域 `cn-shanghai`、服务 `baselineCheck`。凭据禁止放入前端环境变量。缺少配置时公开审核失败，私密保存和本人查看仍可用。

默认全系统并发 2 个审核任务。`SHARE_REVIEW_MAX_CONCURRENT` 只初始化控制行，后续通过 `share_review_control.max_concurrent` 统一调整；任务持久化、租约接管、有限自动重试，页面关闭后继续处理。审核策略变化需升级 `SHARE_REVIEW_POLICY_VERSION`。

公开图片仍存私有桶，公开入口校验记录当前状态后签发短期地址；此次不修改 CDN 或回源鉴权。

完整接口和配置见后端 `docs/api.md` 的「分享公开审核」，提示词说明见后端 `docs/ai-integration.md`。

## 验证结果

- 前端分享模块 17 项测试通过；类型检查、Lint、生产构建通过。
- 后端审核相关 24 项测试通过，包括 17 项分享集成测试、3 项后台执行器测试、2 项 DeepSeek 客户端测试、2 项阿里云客户端测试。
